# Temperature-Prediction-Using-Regression-Models
Developed regression models to predict temperature using historical data. Performed data preprocessing, EDA, feature engineering, and trained models like Linear Regression and Random Forest. Evaluated results using MAE/RMSE with visual trend comparisons.

🔍 Overview

A machine learning project that predicts temperature values based on historical weather data. The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, and training regression models to forecast temperature patterns.

🧠 Key Features

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature engineering for improved predictions

Regression models (Linear Regression, Random Forest, etc.)

Evaluation using MAE, MSE, RMSE

Visualization of trends & model predictions

🧰 Tech Stack

Python

Pandas, NumPy

Scikit-learn

Matplotlib / Seaborn
